# Delta: surface/roster

## ADDED

### R-surface-19  The roster lists every child

WHILE a session runs children THE SYSTEM SHALL list each child with its state.

Acceptance: @R-surface-19

### R-surface-20  The roster counts children awaiting input

WHILE a child awaits input THE SYSTEM SHALL show that count on the roster.

Acceptance: @R-surface-20

### R-surface-21  Attaching brings one child to the foreground

WHEN the user attaches to a child THE SYSTEM SHALL render that child's stream in the foreground view.

Acceptance: @R-surface-21

### R-surface-22  A child can be cancelled alone

WHILE a child runs THE SYSTEM SHALL offer cancel for that child without cancelling its parent.

Acceptance: @R-surface-22
